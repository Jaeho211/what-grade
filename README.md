# 몇 학년? · What Grade

문제당 20초, 초등 1학년~중학교 3학년 범위의 10문제로 수학 나이를 재미로 알아보는 도전 게임. 보기 선택 즉시 답이 확정되며 정답·오답 반응을 0.4초 표시한다. 반응 중에는 입력과 타이머가 멈추고, 다음 문제가 나타나면 20초를 새로 시작한다. 시간 초과는 별도 미응답으로 기록하고 0.8초 안내 후 다음 문제로 넘어간다. 앱 전환 중에도 제한시간은 흐른다. 결과에는 여러 영역의 정답 근거에 따른 단일 학년, 정답 수, 풀이 시간, 건너뛴 수, 시간 기반 숙련도 설명을 표시한다.

## 실행

Node.js 22.12 이상 또는 지원되는 최신 LTS 버전을 사용한다.

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

## 배포

Cloudflare Workers의 정적 파일 호스팅을 사용한다. 계정 인증 후 배포한다.

```sh
npx wrangler login
npm run deploy
```

실제 배포는 아직 수행하지 않았다. 기본 Worker 이름은 `wrangler.jsonc`의 `what-grade`이며 필요시 변경한다.

## 구성

- `src/App.tsx`: 시작, 퀴즈, 결과, 공유 및 답안 해설 화면
- `src/quiz.ts`: 적응형 문제 선택과 수학 나이 계산
- `src/round-clock.ts`: 20초 제한시간, 중복 제출 방지, 풀이 시간 계산
- `src/question-generator.ts`: 학년별 계산·도형·측정·규칙·자료 유형의 숫자·정답·보기·해설을 학년별 범위 안에서 무작위 생성
- `data/questions/math/grade-1.json` ~ `grade-6.json`: 출제 슬롯과 학년·개념 메타데이터 (고정 문항은 런타임에 생성 문항으로 대체)

문제 데이터는 구현 검증용 초안이다. 교과서·성취기준 대조와 사용자 응답 기반 난이도 검증은 아직 필요하다. 결과는 실제 학년이나 전체 수학 능력을 진단하지 않는다. 브라우저에서 채점하므로 경쟁 랭킹 도입 전 서버 채점이 필요하다.

같은 유형도 출제할 때마다 숫자를 새로 뽑는다. 한 회차 안에서는 같은 문제 문구를 재출제하지 않으며, 보기 순서도 섞는다. 회차 간 우연한 중복은 가능하다. 몫 계산은 나누어떨어지도록 만들고, 나머지 유형은 나머지가 남도록 생성하며, 분수 보기는 값이 겹치지 않도록 구성한다.

출발 수준은 초등 5학년이다. 두 문제 모두 정답이면 한 단계 상승, 둘 다 오답(시간 초과 포함)이면 한 단계 하락한다. 내부 level 1~6은 초등 1~6학년, 7~9는 중학교 1~3학년이며 학교급과 학년은 별도 필드로 관리한다. 첫 7문제를 모두 맞히면 마지막 세 문제는 중3 심화 도전이며, 전부 오답이면 마지막 두 문제는 초1에서 출제된다. 모든 학년에 최소 세 영역의 생성 유형을 제공한다. 결과 판정은 출제 수준과 분리하며, 해당 수준 이상의 정답과 인접 선수 수준을 포함한 세 영역의 정답 근거가 필요하다. 중3 결과는 중3 심화 문제의 서로 다른 세 영역을 직접 맞혀야 한다. 풀이 시간은 유형별 기준으로 숙련도와 판정 확신을 보조하며 학년 자체를 바꾸지 않는다. 전체 교육과정 진단을 의미하지 않는다.

정답이면 선택한 보기에 ✓, 오답이면 −를 표시한다. 3연속 정답부터 연속 횟수를 안내하고 결과에는 최고 연속 정답을 표시한다. 오답·시간 초과 시 현재 연속 기록은 초기화되며 재도전은 모든 회차 기록을 초기화한다. 반응 안내 시간은 풀이 시간에 포함하지 않는다.
