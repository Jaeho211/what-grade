# 중학교 수학 영역 및 학년별 내용

- 대상: 대한민국 중학교 1~3학년
- 기준: 2022 개정 교육과정
- 정리 날짜: 2026-10-03
- 목적: What Grade의 중학교 문제 확장을 위한 개념 분류와 출제 설계
- 검증 상태: 공식 영역과 적용 일정은 교육부 자료 확인. 아래 학년별 세부 배치는 교과서·성취기준 원문 대조 전 초안.
- 구현 상태: 초등 1~6학년과 중학교 1~3학년 출제를 구현했다. 중학교는 학년별 3개 유형(정수 덧셈·일차방정식·정비례 / 지수법칙·연립방정식·피타고라스 / 제곱근·이차방정식의 양수 해·이차함수)을 제공한다.

## 교육과정 기준

2022 개정 교육과정의 중학교 적용 일정은 다음과 같다.

| 학년 | 적용 시작 | 2026학년도 기준 |
|---|---|---|
| 중학교 1학년 | 2025년 3월 | 2022 개정 적용 |
| 중학교 2학년 | 2026년 3월 | 2022 개정 적용 |
| 중학교 3학년 | 2027년 3월 | 아직 2015 개정 적용 |

앱의 향후 확장 기준은 2022 개정으로 통일하되, 현재 재학생의 교육과정과 구분한다. 공식 성취기준은 중학교 1~3학년군을 기준으로 제시되므로, 아래 표를 공식 학년별·학기별 단원표로 간주하지 않는다. 학년 배치는 실제 사용할 교과서와 대조해 확정한다.

## 공식 수학 영역

| 공식 영역 | 중학교의 대표 개념 | 게임 문제 형태 |
|---|---|---|
| 수와 연산 | 소인수분해, 정수와 유리수, 유리수와 순환소수, 제곱근과 실수 | 짧은 계산, 수의 성질 판단 |
| 변화와 관계 | 문자와 식, 방정식·부등식, 좌표와 그래프, 함수 | 식의 값, 미지수, 그래프의 한 점 찾기 |
| 도형과 측정 | 기본 도형, 작도·합동, 도형의 성질, 닮음, 피타고라스 정리, 삼각비, 원 | 각도·길이 계산, 간단한 그림 해석 |
| 자료와 가능성 | 자료의 정리·해석, 경우의 수와 확률, 대푯값·산포도, 자료 사이의 관계 | 작은 자료표, 확률, 산점도 읽기 |

2022 개정의 자료 영역에는 상자그림도 포함된다. 사분위수·상자그림 등 개정 내용의 세부 학년 배치는 원문과 교과서 확인 후 확정하며, 기존 교육과정의 단원 배치를 그대로 옮기지 않는다.

## 학년별 대표 내용 초안

| 출제 학년 | 수와 연산 | 변화와 관계 | 도형과 측정 | 자료와 가능성 |
|---|---|---|---|---|
| 중1 | 소인수분해, 최대공약수·최소공배수, 정수·유리수와 사칙연산 | 문자와 식, 일차방정식, 좌표평면, 정비례·반비례 | 점·선·면과 각, 위치 관계, 작도와 합동, 평면·입체도형의 측정 | 자료의 분포, 도수분포표·히스토그램, 상대도수 등 기초 자료 해석 |
| 중2 | 유리수와 순환소수 | 지수법칙, 단항식·다항식 계산, 일차부등식, 연립일차방정식, 일차함수 | 삼각형·사각형의 성질, 도형의 닮음, 피타고라스 정리 | 경우의 수, 확률 |
| 중3 | 제곱근과 실수, 근호를 포함한 계산 | 다항식의 곱셈·인수분해, 이차방정식, 이차함수 | 삼각비, 원의 성질 | 대푯값·산포도, 산점도와 상관관계 등 자료 비교·해석 |

이 표는 대표 개념의 출제 후보 목록이며 전체 성취기준 목록이 아니다. 특히 통계 개념의 학년별 배치는 추가 검증 대상이다. 성취기준 코드는 원문 확인 전 임의로 부여하지 않는다.

## 20초 도전에 맞는 출제 후보

게임의 우선 목적은 흥미, 재도전, 친구와 결과 공유다. 교육과정은 문제를 분류하는 기준으로 사용하고, 결과를 학습 진단으로 표현하지 않는다.

| 출제 학년 | 유형 | 예시 | 정답 | 생성 시 조건 |
|---|---|---|---|---|
| 중1 | 정수 계산 | `−7 + 12 = ?` | `5` | 음수·양수를 섞고 부호를 명확히 표시 |
| 중1 | 일차방정식 | `3x + 2 = 17`의 해 | `5` | 정수 해를 먼저 뽑아 식을 구성 |
| 중1 | 정비례 | `y = 3x`에서 `x = 4`일 때 y | `12` | 짧은 대입 계산으로 제한 |
| 중2 | 지수법칙 | `2³ × 2² = 2ⁿ`에서 n | `5` | 같은 밑을 사용하고 정답 표현 통일 |
| 중2 | 연립일차방정식 | `x + y = 7`, `x − y = 1`에서 x | `4` | 정수 해를 먼저 뽑고 두 식이 독립인지 확인 |
| 중2 | 피타고라스 정리 | 직각삼각형의 두 직각변이 3, 4일 때 빗변 | `5` | 피타고라스 수 사용, 변의 역할 명시 |
| 중2 | 확률 | 공정한 주사위에서 짝수가 나올 확률 | `1/2` | 표본공간과 동일한 가능성을 명시 |
| 중3 | 제곱근 | `√49 = ?` | `7` | `√49`와 ‘49의 제곱근’을 구분 |
| 중3 | 인수분해 | `x² − 9`를 인수분해 | `(x − 3)(x + 3)` | 곱의 순서가 다른 동치 보기 중복 방지 |
| 중3 | 이차방정식 | `x² = 25`의 모든 해 | `−5, 5` | 해 하나만 묻는지 모든 해를 묻는지 명시 |
| 중3 | 이차함수 | `y = x²`에서 `x = −3`일 때 y | `9` | 음수 대입 시 괄호·제곱 범위 표시 |

처음에는 정수 계산 → 일차방정식 → 지수법칙·연립방정식 → 제곱근·이차방정식처럼 코드로 안전하게 생성할 수 있는 유형부터 추가한다. 길이가 긴 응용 문제, 증명, 작도 수행은 20초 객관식의 초기 범위에서 제외한다. 도형·그래프는 작은 화면에서 명확한 그림을 제공할 수 있을 때 추가한다.

## 문제 생성 및 보기 규칙

- 교육과정 학년과 계산 난이도를 따로 관리한다. 같은 개념도 숫자 크기와 계산 단계 수에 따라 난도가 달라진다.
- 방정식은 해에서 역으로 식을 만들고, 유일한 해 또는 요구하는 모든 해가 존재하는지 확인한다.
- 분수 보기는 기약분수로 통일하고 분모가 1이면 정수로 표시한다.
- 근호는 유형에서 요구하는 표준 형태로 표시한다. 소수 근삿값과 정확한 값을 혼용하지 않는다.
- 식·분수·근호 보기는 문자열뿐 아니라 수학적으로 같은 값이나 식인지 검사한다.
- 오답은 부호 실수, 지수법칙 착각, 이항 실수 등에서 만들되 정답과 동치가 되지 않게 한다.
- 생성한 숫자로 정답과 해설을 함께 계산하고, 보기 섞기 후에도 정답 위치를 유지한다.
- 문장 읽기나 그림 해독에 시간이 소모되는 문제는 실제 플레이로 20초 적합성을 확인한다.

## 초등에서 중학교로 확장할 때의 데이터 설계

기존 `Question.grade`는 현재 초등 학년과 출제 수준을 동시에 나타낸다. 중학교 구현 시 학교급을 명확히 구분한다.

| 정보 | 확장안 예시 | 용도 |
|---|---|---|
| `curriculum` | `2022` | 교육과정 버전 |
| `schoolLevel` | `middle` | 초등·중학교 구분 |
| `grade` | `1` | 학교급 안에서의 학년 |
| `gradeBand` | `1~3` | 공식 학년군, 학교급과 함께 해석 |
| `level` | `7` | 초1~6 = 1~6, 중1~3 = 7~9인 내부 출제 순서 |
| `domain` | `변화와 관계` | 공식 영역 |
| `concept` | `일차방정식` | 문제 생성 유형 |
| `prerequisites` | `정수 계산`, `문자식` | 선수 개념 |
| `difficulty` | `기초` | 같은 학년 안의 난도 |

학교급·grade·level 분리는 구현했다. 나머지 세부 메타데이터는 확장 설계안이다. 중1을 `grade: 7`로만 저장하고 화면에서 ‘초등 7학년’으로 표시하는 방식은 사용하지 않는다. 출제 로직은 `level`, 화면은 학교급과 `grade`를 사용하도록 함께 수정한다.

## 게임 확장 체크리스트

- [ ] 학년별 후보를 2022 개정 수학과 원문·교과서와 대조한다.
- [ ] 각 후보의 공식 성취기준을 연결한다.
- [ ] 중1~3의 여러 개념별 생성 함수와 동치 보기 검사를 구현한다.
- [ ] 초6 → 중1의 출제 경계 및 최대 수준을 확장한다.
- [ ] 10문제에서 중학교 수준에 도달할 수 있는 출발점·승급 규칙을 검토한다.
- [ ] 결과와 공유 문구에서 ‘초등’과 ‘중학교’를 구분한다.
- [ ] 문제별 20초 안에 읽고 풀 수 있는지 모바일로 확인한다.
