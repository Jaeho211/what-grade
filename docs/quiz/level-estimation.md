# 출제 및 수학 나이 계산 규칙

갱신: 2026-10-03. 재미를 위한 게임 규칙이며 학습 진단으로 검증된 모델이 아니다.

## 진행

- 총 10문제, 문제당 20초이며 초등 5학년 수준에서 시작한다.
- 내부 출제 수준은 1~9: 초등 1~6학년, 중학교 1~3학년 순이다.
- 학교급과 학교급 안의 학년을 따로 저장한다. 중1의 내부 level은 7, grade는 1이다.
- 두 문제씩 같은 수준에서 출제하고, 두 번째는 가능한 경우 다른 개념을 선택한다.
- 둘 다 정답이면 한 단계 상승, 둘 다 오답 또는 시간 초과면 한 단계 하락한다.
- 정오답이 섞이면 수준을 유지하며, 범위는 1~9로 제한한다.
- 보기 선택 즉시 확정하고 정답·오답은 0.4초, 시간 초과는 0.8초 안내 후 다음 문제로 이동한다. 안내 중 타이머와 입력은 멈추며 다음 문제는 20초를 새로 시작한다.
- 숫자·정답·해설을 함께 생성하고 보기 순서를 섞는다. 한 회차의 문제 문구는 중복되지 않는다.

## 10문제와 범위

| 응답 | 실제 출제 수준(두 문제씩) | 결과 |
|---|---|---|
| 모두 정답 | 초5 → 초6 → 중1 → 중2 → 중3 | 중학교 3학년 |
| 모두 오답 | 초5 → 초4 → 초3 → 초2 → 초1 | 초등 1학년 |
| 모든 쌍에서 정오답 혼합 | 초5 유지 | 초등 5학년 |

초3 출발에서는 두 문제마다 한 단계 오르는 규칙으로 10문제 안에 중3을 출제할 수 없다. 전체 9단계의 양 끝에 도달할 수 있도록 초5 출발로 조정했다.

## 결과

- 마지막 두 답변까지 반영한 단일 단계로 ‘초등 6학년’, ‘중학교 1학년’처럼 표시한다.
- 정답 수, 풀이 시간 합계, 시간 초과 수, 최고 연속 정답을 표시한다. 안내 전환 시간은 풀이 시간에서 제외한다.
- 풀이 속도는 학년 계산에 추가 반영하지 않는다.
- 공유 문구도 같은 학교급·학년을 사용하며 중3에서는 최고 단계 재도전 문구를 표시한다.
- 정답 해설은 결과의 접힌 ‘정답 확인’에서 제공한다.

## 한계

짧은 계산 위주의 일부 개념으로 구성되어 있고, 학년별 단원 배치는 교과서 대조 전 초안이다. 우연한 정답, 읽기 속도, 개념별 편차를 충분히 모델링하지 않는다. 화면에는 재미로 보는 수학 나이임을 표시한다. 전체 교육과정 성취나 실제 재학 학년을 진단하지 않는다.
