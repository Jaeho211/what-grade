# 초기 출제 및 수준 추정 규칙

상태: 구현 검증용 휴리스틱. 실제 응답을 통한 타당도 검증 전.

## 진행

- 총 10문제로 종료하며 시작 수준은 3학년이다.
- 두 문항씩 현재 수준을 확인한다.
- 두 번째 문항은 가능한 경우 다른 개념에서 고른다. 선택지 순서도 무작위로 섞는다.
- 두 문항 모두 정답이면 다음 수준을 한 학년 올린다.
- 두 문항 모두 오답 또는 모름이면 다음 수준을 한 학년 내린다.
- 정답과 오답이 섞이면 현재 수준을 유지한다.
- 출제 수준은 1~6학년 범위로 제한한다.
- 같은 문제는 한 회차에서 다시 출제하지 않는다.
- 해당 학년의 미출제 문제를 무작위로 선택한다. 소진되면 가장 가까운 학년의 문제를 선택한다.

## 결과

- 마지막 답변까지 반영한 수준을 중심으로 앞뒤 한 학년 범위를 표시한다.
- 표시 범위는 1~6학년 안으로 제한한다.
- 결과는 수와 연산에 한정한 가벼운 추정임을 명시한다.
- 정답 개념과 오답·모름 개념을 각각 보여준다. 동일 개념이 양쪽에 나타날 수 있다.
- 정답과 해설은 모든 답변을 마친 뒤 제공한다.

## 한계 및 후속 검증

한 학년 안의 개념별 편차나 우연한 정답을 충분히 모델링하지 않는다. 초기 문제는 계산 비중이 높고 난이도·선수 개념 메타데이터는 추가 검토가 필요하다. 모든 학년의 대표 개념을 충분히 평가하는 규칙으로 개선하고, 사용자 응답으로 결과 범위와 문제 난도를 검증해야 한다.
