# 출제 및 수학 나이 계산 규칙

갱신: 2026-10-03. 재미를 위한 게임 규칙이며 검증된 학습 진단 모델이 아니다.

## 진행

- 총 10문제, 모든 유형은 문제당 20초. 초등 5학년 수준에서 시작한다.
- 내부 수준 1~9는 초등 1~6학년과 중학교 1~3학년을 나타낸다.
- 출제 난이도 탐색은 두 문제씩: 모두 정답이면 한 단계 상승, 모두 미정답이면 하락, 혼합이면 유지한다.
- 탐색 수준은 결과 학년이 아니다. 미출제 학년을 정답 두 개만으로 확정하지 않는다.
- 해당 학년에서 덜 출제된 영역을 먼저 고르고, 개념을 균등하게 선택한 뒤 템플릿을 선택한다. 기존 계산 템플릿 개수가 많아도 계산만 반복되지 않는다.
- 보기 선택은 즉시 확정하며 정오답 안내 0.4초, 시간 초과 안내 0.8초 후 다음 문제로 이동한다.
- 건너뛰기는 안내와 정답 공개 없이 즉시 이동한다. 오답·시간 초과와 별도 기록하되 탐색에는 미정답으로 반영한다.
- 답을 확정한 뒤에는 타이머가 멈추고 중복 입력을 무시한다. 제한 시간이 지난 입력은 시간 초과로 처리한다.

## 학년 근거

- 탐색 수준에서 아래로 내려가며 정답 근거가 있는 수준을 찾는다.
- 해당 수준 또는 그 이상에서 정답이 있어야 하고, 해당 수준과 바로 아래 선수 수준 이상을 합쳐 서로 다른 세 영역의 정답이 있어야 한다.
- 하나의 유형 또는 하나의 영역만 잘 푸는 경우 학년을 확정하지 않는다. 피타고라스 문제만 맞히는 경우도 같다.
- 정답 근거가 부족하면 ‘학년 판정 보류’를 표시한다. 모두 오답이라고 초1 능력이 확인된 것으로 표시하지 않는다.
- 근거가 있으면 기준 수준 전후 한 단계 범위를 표시한다. 이 범위는 통계적 신뢰구간이 아니며 실제 학년 진단이 아니다.

## 시간 반영

- 실제 풀이 시간은 문제 시작부터 입력 또는 시간 초과까지 기록한다. 화면 전환 시간은 제외한다.
- 유형별 예상 풀이 시간은 7~15초의 임시 기준이다. 제한 시간은 모두 20초로 유지한다.
- 근거 수준의 정답 중 시간이 기록된 3문제 이상에서 70% 이상이 유형별 예상 시간 이내이면 ‘비교적 뚜렷한 결과’, 그 외는 ‘잠정 결과’를 표시한다.
- 1초 미만 정답은 속도 근거에서 제외한다. 정답 자체는 인정하지만 빠른 추측으로 판정 확신을 높이지 않는다.
- 느린 정답도 개념 이해 근거로 인정한다. 풀이 시간만으로 학년을 올리거나 낮추지 않는다.
- 오답·시간 초과·건너뛰기에는 속도 가점이 없다.
- 시간 기준과 확신 문구는 게임용 휴리스틱이다. 실제 사용자 풀이 기록으로 보정하기 전 검증된 숙련도 척도로 해석하지 않는다.

## 출제 영역 확장

| 학년 | 기존 계산 외 추가 개념 |
|---|---|
| 초1 | 모양 찾기, 수의 순서 |
| 초2 | 길이 단위, 수의 규칙 |
| 초3 | 시간 계산, 정사각형의 변 |
| 초4 | 각도 계산, 수의 규칙 |
| 초5 | 직사각형 넓이, 평균 |
| 초6 | 직육면체 부피, 백분율 |
| 중1 | 삼각형 내각, 중앙값 |
| 중2 | 일차함수 기울기, 확률 |
| 중3 | 인수분해, 삼각비, 분산 |

학년별 최소 세 영역을 확보했다. 짧은 문장과 작은 수 중심의 기초 문제이며 교육과정 전체를 대표하지 않는다. 숫자·보기·정답·해설을 함께 생성하고 정답을 보존하며 보기 순서를 섞는다.

## 결과

정답 수, 풀이 시간 합계, 시간 초과 수, 건너뛴 수, 최고 연속 정답, 학년 범위 또는 판정 보류, 시간 기반 숙련도 설명을 표시한다. 정답과 해설은 결과의 접힌 ‘정답 확인’에서 제공한다.
