# 출제 및 수학 나이 계산 규칙

갱신: 2026-10-03. 재미를 위한 게임 규칙이며 검증된 학습 진단 모델이 아니다.

## 진행

- 총 10문제, 모든 유형은 문제당 20초. 초등 5학년 수준에서 시작한다.
- 내부 수준 1~10은 초등 1~6학년, 중학교 1~3학년, 고등학교 1학년을 나타낸다.
- 출제 난이도 탐색은 두 문제씩: 모두 정답이면 한 단계 상승, 같은 단계의 두 문제를 각각 예상 풀이 시간의 절반 이내에 맞히면 두 단계 상승, 모두 미정답이면 하락, 혼합이면 유지한다.
- 오답·시간 초과·건너뛰기 이후 3연속 이상 정답을 두 문제 묶음 끝에서 확인하면 회차당 한 번 추가 한 단계 상승한다. 초반 실수 뒤 실력을 보인 경우의 만회 기회다. 속도 상승과 중복하여 세 단계 상승하지 않는다.
- 6문제 뒤 최근 3연속 정답이고 마지막 출제가 중1 이상이면 7번째는 최소 중3 확인 문제다. 빠른 정답으로 이미 고1에 도달했으면 유지한다. 7번째를 맞히고 최근 3연속 정답이면 고1 또는 중3 심화 확인을 시작한다. 마지막 3문제는 확인 수준을 유지하되 해당 수준에서 2연속 미정답이면 한 단계 내려가 남은 문제로 확인한다. 초반 전부 정답일 필요는 없다.
- 탐색 수준은 결과 학년이 아니다. 미출제 학년을 정답 두 개만으로 확정하지 않는다.
- 목표 학년에서 아직 출제하지 않은 개념을 먼저 고른다. 모두 출제했을 때만 회차 전체에서 출제 횟수가 가장 적은 개념을 재출제하며, 가능한 경우 직전 개념은 피한다. 정답·오답·넘어가기·시간 초과 모두 출제 이력으로 센다.
- 이 후보 안에서 판정에 아직 정답 근거가 없는 영역을 우선한 뒤 해당 학년에서 덜 출제된 영역을 고르고, 개념을 균등하게 선택한 뒤 템플릿을 선택한다. 기존 계산 템플릿 개수가 많아도 계산만 반복되지 않는다.
- 보기 선택은 즉시 확정하며 정오답 안내 0.4초, 시간 초과 안내 0.8초 후 다음 문제로 이동한다.
- 건너뛰기는 안내와 정답 공개 없이 즉시 이동한다. 오답·시간 초과와 별도 기록하되 탐색에는 미정답으로 반영한다.
- 답을 확정한 뒤에는 타이머가 멈추고 중복 입력을 무시한다. 제한 시간이 지난 입력은 시간 초과로 처리한다.

## 학년 근거

- 다음 문제의 탐색 수준과 최종 학년 계산은 분리한다. 전체 응답을 이용하여 초1~고1 각 수준을 독립적으로 평가하고 가장 높은 통과 수준을 결과로 표시한다. 응답 순서나 속도만 바꾸어도 최종 결과는 같아야 한다.
- 통과 기준은 정답 3개 이상, 서로 다른 3개 영역, 관련 문제 정답률 75% 이상이다. 해당 수준 이상의 정답이 최소 하나 있어야 한다.
- 초1~중2는 해당 수준과 바로 아래 선수 수준을 평가한다. 상위 수준의 정답도 근거로 인정하지만 상위 수준의 실패는 낮은 수준의 정답률을 깎지 않는다.
- 중3은 중3 심화와 고1의 정답을 근거로 사용한다. 중3 심화의 모든 응답과 고1 정답을 평가한다. 고1은 고1 심화의 모든 응답을 평가한다. 선수 수준의 정답으로 상위 학년을 확정하지 않는다.
- 예: 고1에서 3/3 또는 3/4 정답이고 세 영역을 통과하면 고1, 3/5 정답이면 고1 통과 조건 부족이다. 75%는 검증 전 게임용 초기 기준이다.
- 하나의 영역만 잘 푸는 경우 학년을 확정하지 않는다. 피타고라스 문제만 맞히는 경우도 같다.
- 통과 수준이 없으면 초1~중2 중 두 영역·정답 2개·정답률 75%의 부분 근거가 있는 가장 높은 수준을 추정한다. 부분 근거도 없으면 가장 낮게 출제한 수준의 바로 아래 학년을 추정한다(최저 초1). 이 경우 근거 부족 상태와 추정 안내를 표시한다. 이는 낮은 학년을 직접 검증했다는 뜻이 아니다.
- 결과와 공유 문구는 한 학년으로 표시한다. 게임용 추정이며 실제 능력 진단이 아니다.

## 시간 반영

- 실제 풀이 시간은 문제 시작부터 입력 또는 시간 초과까지 기록한다. 화면 전환 시간은 제외한다.
- 유형별 예상 풀이 시간은 7~17초의 임시 기준이다. 제한 시간은 모두 20초로 유지한다.
- 근거 수준의 정답 중 시간이 기록된 3문제 이상에서 70% 이상이 유형별 예상 시간 이내이면 내부 확신도를 높게 기록한다. 확신도 문구는 결과 화면에 표시하지 않고 풀이 숙련도 설명만 제공한다.
- 1초 미만 정답은 속도 근거에서 제외한다. 정답 자체는 인정하지만 난이도 가속과 판정 확신에는 사용하지 않는다.
- 느린 정답도 개념 이해 근거로 인정한다. 속도는 다음 문제 탐색을 가속하며, 최종 학년에는 해당 수준의 여러 영역 정답 근거가 반드시 필요하다.
- 오답·시간 초과·건너뛰기에는 속도 가점이 없다.
- 시간 기준과 확신 문구는 게임용 휴리스틱이다. 실제 사용자 풀이 기록으로 보정하기 전 검증된 숙련도 척도로 해석하지 않는다.

오답은 빠뜨린 해, 부호·조건 혼동 등으로 구성한다. 문제마다 큰 숫자보다 개념의 적용 조건을 우선한다. 중1~고1의 예상 풀이 시간은 개편에 맞춰 17초의 임시 기준으로 통일했으며 실제 사용자 응답으로 보정해야 한다. 표의 학년은 게임용 출제 배치이며 교육과정 전체의 진단을 의미하지 않는다.

## 20초 읽기·계산 부담 조정

- 설계 목표는 읽기 약 5초와 판단·계산 약 15초다. 실제 풀이 시간의 보장은 아니며 플레이로 검증한다.
- 문장은 1~2개, 핵심 개념은 하나로 제한한다. 불필요한 상황 설명과 중첩된 조건을 줄인다.
- 닮음은 넓이가 몇 배인지, 자료 변환은 배율 한 번만 묻는다. 역함수는 선형함수의 기울기 관계를 묻는다.
- 집합은 실제 원소를 나열해 조건을 짧게 제시한다. 확률은 작은 공 개수와 동시 추출로 표본공간을 명확히 한다.
- 인수분해·복소수·합성함수·피타고라스·조합의 숫자 범위를 줄인다. 상위 학년의 세 영역 정답 근거는 유지한다.
- 어려운 이유가 문장, 계산, 개념 중 무엇인지 실제 응답과 사용자 피드백으로 확인한다.
